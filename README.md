# ML-Based PID Auto-Tuner for DC Motor



## 1. Project Overview



This project develops a simulation-based PID auto-tuning system for a DC motor. It evaluates different Proportional (Kp), Integral (Ki), and Derivative (Kd) controller gains and measures the resulting motor response.



The generated dataset can be used by the machine-learning component to investigate relationships between controller parameters and motor performance.



## 2. Project Objectives



- Simulate the response of a DC motor.

- Implement a PID controller.

- Calculate motor-response performance metrics.

- Generate a dataset using different PID gain combinations.

- Validate and rank the generated configurations.

- Prepare the dataset and documentation for the machine-learning component.

## 7. PID Controller



The PID controller uses three gains:



- **Kp â€” Proportional gain:** Responds to the current control error.

- **Ki â€” Integral gain:** Responds to accumulated error.

- **Kd â€” Derivative gain:** Responds to the rate of change of error.



Main script:



`src/pid\_controller.py`



The controller is evaluated by comparing the motor's actual speed with the target speed.



## 8. Performance Metrics



The project evaluates PID configurations using the following metrics:



- **Final speed (RPM):** Motor speed at the end of the simulation.

- **Final error (RPM):** Difference between the target speed and final motor speed.

- **Steady-state error (%):** Final speed error expressed as a percentage of the target speed.

- **Overshoot (%):** Amount by which the response exceeds the target speed.

- **Rise time (s):** Time taken to reach the specified rise-time thresholds.

- **Settling time (s):** Time required for the response to enter and remain within the specified settling band.

- **IAE (RPMÂ·s):** Integral of the absolute speed error over time.



Lower IAE indicates a smaller accumulated absolute tracking error over the evaluated simulation interval.



## 9. Dataset Generation

- Configurations: 180

- Columns: 12

- Target speed: 100 RPM

- Simulation duration: 10 seconds

- Controller parameters: Kp, Ki, and Kd



The dataset contains the controller gains, target and duration settings, final motor speed, error measurements, overshoot, rise time, settling time, and IAE.

## 14. Current Limitations



- The dataset uses a single target speed of 100 RPM and one motor simulation setup.

- The 180 configurations vary PID gains rather than motor characteristics.

- Consequently, this dataset alone cannot establish how optimal PID gains change across different motors, loads, or target speeds.

- Missing rise-time and settling-time measurements require careful treatment in downstream analysis.

- Structural validation does not independently verify the physical accuracy of the motor model.



A model intended to recommend gains for different motor conditions will require suitable training examples covering those conditions.
